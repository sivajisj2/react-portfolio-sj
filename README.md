# Sivaji Gadidala Portfolio

Responsive portfolio for Rust backend, AI infrastructure, blockchain, and full-stack engineering roles.

## Live site

https://sivajisj2.github.io/react-portfolio-sj/

## Run locally

```sh
npm install
npm run dev
```

## Contact and scheduling

The enquiry form uses FormSubmit's documented HTML POST endpoint, named fields, a spam honeypot, a table email template, and a thank-you redirect. On first use, FormSubmit sends an activation email to the portfolio inbox; confirm it before expecting subsequent submissions to arrive. Meeting bookings open the public Sivaji Scheduler app, which displays available time slots.

## Projects

Project cards link to repositories under `sivajisj2`. Project READMEs document implementation details and prototype limits.

## Deployment

A GitHub Actions workflow builds the Vite application and publishes `dist/` to GitHub Pages on pushes to `main`.
